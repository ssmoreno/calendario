# SS Calendar design

SS Calendar is a quiet, full-page workspace with three areas: the inline Agent, four upcoming Google Calendar events, and a profile menu. There is no calendar grid or event editor.

The desktop layout centers the wordmark above two balanced columns. The Agent starts as a compact composer and expands into a bounded conversation. Upcoming events use restrained bordered cards whose details expand in place. The profile menu contains identity, Settings, and Log out.

On narrow screens the columns stack, preserving Agent first and Upcoming events second. Empty, loading, disconnected, authorization, and service-error states occupy the same stable event area. Keyboard focus uses the shared blue outline, native details controls retain semantic disclosure behavior, and reduced-motion preferences disable nonessential transitions.

The existing light/dark tokens, Instrument Sans UI type, and IBM Plex Mono temporal metadata remain the visual foundation.
